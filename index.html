分享 / 导入配置

① 分享链接（含三个点位的视频与图片）

复制后发给他人，对方用浏览器打开该链接，看到的就是您设置的内容。

② 导入配置

粘贴他人分享的 JSON，或本机备份的 JSON，点击导入即可应用。

⚠ 检测到本地视频：本地视频文件只存在当前浏览器中，无法随分享链接或 JSON 同步。其他设备打开时该点位会显示“本地视频不可用”。如需分享，请把视频上传到网络后改用网络地址。
为什么改完分享出去没变化？
网页里的修改保存在「当前设备浏览器」中，不会跟随文件或链接传播。
· 本页以 file:// 方式打开时，分享链接只在本机有效，请把 HTML 上传到任意静态托管（GitHub Pages、Gitee Pages、Netlify 等）后再分享；
· 更彻底的做法：直接把本文件顶部 DEFAULT_SITES 里的链接改成您的，再分享这个 HTML 文件，任何设备打开都是新内容。
